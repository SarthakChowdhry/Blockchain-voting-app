# Blockchain Voting App

A decentralized voting application built using **Hardhat**, **Solidity**, and **React.js**. This project demonstrates how blockchain technology can create a secure, transparent, and tamper-proof voting system.

---

## Features

- Secure smart contract voting
- Wallet authentication with MetaMask
- One wallet = one vote
- Real-time election results
- Decentralized and transparent
- React frontend with Web3 integration
- Hardhat for smart contract development and deployment

---

## Tech Stack

### Blockchain
- Solidity
- Hardhat
- Ethers.js

### Frontend
- React.js
- CSS / Tailwind CSS / Bootstrap

### Wallet
- MetaMask
